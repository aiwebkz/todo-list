# Список задач (To-Do List)

Простое веб-приложение для управления задачами на чистом HTML, CSS и JavaScript — без фреймворков и сборки.

## Возможности

- ➕ Добавление новых задач
- ✅ Отметка выполненных задач
- ✕ Удаление задач (по одной или все выполненные сразу)
- 💾 Сохранение задач в `localStorage` — список не пропадает после обновления страницы
- Фильтры: все / активные / выполненные
- Адаптивная вёрстка и тёмная тема (по настройкам системы)

## Запуск

Откройте `index.html` в браузере — больше ничего не нужно.

## Структура

```
index.html   — разметка
style.css    — стили
script.js    — логика и работа с localStorage
```

## Использованные AI-инструменты

Проект создан с помощью **Claude Code** (Anthropic): код написан по текстовому описанию задачи, затем проверен в браузере.
